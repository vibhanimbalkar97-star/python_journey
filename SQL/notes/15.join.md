# **SQL JOIN (Simple Explanation)**

**JOIN is used to combine data from two or more tables using a related column.**

In simple words: JOIN se hum multiple tables ka related data ek saath dekh sakte hain.

### **Example**

**students table**

| student_id | name  |
| ---------- | ----- |
| 1          | Rahul |
| 2          | Priya |
| 3          | Amit  |

**marks table**

| mark_id | student_id | marks |
| ------- | ---------- | ----- |
| 101     | 1          | 85    |
| 102     | 2          | 90    |
| 103     | 4          | 75    |

### **1. INNER JOIN**

Returns only matching records from both tables.

```
SELECT students.name, marks.marks
FROM students
INNER JOIN marks
ON students.student_id = marks.student_id;
```

Result:

| name  | marks |
| ----- | ----- |
| Rahul | 85    |
| Priya | 90    |

### **2. LEFT JOIN**

Returns all records from the left table and matching records from the right table. No match = `NULL`.

```
SELECT students.name, marks.marks
FROM students
LEFT JOIN marks
ON students.student_id = marks.student_id;
```

Result:

| name  | marks |
| ----- | ----- |
| Rahul | 85    |
| Priya | 90    |
| Amit  | NULL  |

### **3. RIGHT JOIN**

Returns all records from the right table and matching records from the left table.

```
SELECT students.name, marks.marks
FROM students
RIGHT JOIN marks
ON students.student_id = marks.student_id;
```

Result:

| name  | marks |
| ----- | ----- |
| Rahul | 85    |
| Priya | 90    |
| NULL  | 75    |

### **4. FULL OUTER JOIN**

Returns all records from both tables, matching where possible.

```
SELECT students.name, marks.marks
FROM students
FULL OUTER JOIN marks
ON students.student_id = marks.student_id;
```

Result:

| name  | marks |
| ----- | ----- |
| Rahul | 85    |
| Priya | 90    |
| Amit  | NULL  |
| NULL  | 75    |

### **5. CROSS JOIN**

Combines every row of the first table with every row of the second table.

```
SELECT students.name, marks.marks
FROM students
CROSS JOIN marks;
```

3 students × 3 marks = **9 rows**.

### **Quick revision**

| JOIN       | What it returns            |
| ---------- | -------------------------- |
| INNER      | Only matching rows         |
| LEFT       | All left + matching right  |
| RIGHT      | All right + matching left  |
| FULL OUTER | All rows from both tables  |
| CROSS      | Every possible combination |
| SELF       | A table joined with itself |

### **Important interview points**

- `ON` specifies the matching condition.
- `JOIN` alone means `INNER JOIN` in PostgreSQL.
- JOIN does not require a declared foreign key; you can join using matching columns.
- Always use table aliases to write cleaner queries.

```
SELECT s.name, m.marks
FROM students AS s
JOIN marks AS m
ON s.student_id = m.student_id;
```

**Remember:** INNER = matching only; LEFT = everything on left; RIGHT = everything on right; FULL = everything from both.

# **SQL String Functions — Beginner to Pro (PostgreSQL)**

String functions are used to **manipulate, search, modify, combine and extract text** from a column.

Example table: `employees`

| id | name        | email            |
| -- | ----------- | ---------------- |
| 1  | Amit Sharma | amit\@gmail.com  |
| 2  | PRIYA       | priya\@gmail.com |
| 3  | Rahul Kumar | rahul\@gmail.com |

## **1. Basic string functions**

| Function    | Purpose                      | Example                    |
| ----------- | ---------------------------- | -------------------------- |
| `UPPER()`   | Convert to uppercase         | `UPPER('hello')` → HELLO   |
| `LOWER()`   | Convert to lowercase         | `LOWER('HELLO')` → hello   |
| `LENGTH()`  | Count characters             | `LENGTH('Hello')` → 5      |
| `TRIM()`    | Remove spaces from both ends | `TRIM(' Hi ')` → Hi        |
| `LTRIM()`   | Remove spaces from left      | `LTRIM(' Hi')` → Hi        |
| `RTRIM()`   | Remove spaces from right     | `RTRIM('Hi ')` → Hi        |
| `REVERSE()` | Reverse text                 | `REVERSE('hello')` → olleh |

Examples:

```
SELECT UPPER(name) FROM employees;

SELECT LOWER(email) FROM employees;

SELECT LENGTH(name) FROM employees;

SELECT TRIM('   Hello   ');
```

**Interview tip:** `LENGTH()` counts characters in PostgreSQL text, not the number of bytes.

## **2. Combine and join strings**

\| Function / Operator | Purpose | Example |\
\|---|---|---|\
\| `CONCAT()` | Combine strings | `CONCAT('Hello', ' World')` |\
\| `CONCAT_WS()` | Combine using separator | `CONCAT_WS('-', '2026','11','21')` |\
\| `||` | String concatenation operator | `'Hello' || ' World'` |

```
-- Combine first and last name
SELECT CONCAT(first_name, ' ', last_name)
FROM employees;

-- Combine with separator
SELECT CONCAT_WS(' - ', name, email)
FROM employees;

-- Using ||
SELECT 'Hello' || ' World';
```

**Difference:** `CONCAT()` ignores NULL arguments. `||` returns NULL if either input is NULL.

## **3. Extract part of a string**

| Function       | Purpose                   | Example                                |
| -------------- | ------------------------- | -------------------------------------- |
| `SUBSTRING()`  | Extract characters        | `SUBSTRING('JavaScript', 1, 4)` → Java |
| `LEFT()`       | Get characters from left  | `LEFT('Hello', 2)` → He                |
| `RIGHT()`      | Get characters from right | `RIGHT('Hello', 2)` → lo               |
| `SPLIT_PART()` | Split text and get a part | `SPLIT_PART('a-b-c', '-', 2)` → b      |

```
-- First 3 characters
SELECT LEFT(name, 3) FROM employees;

-- Last 4 characters
SELECT RIGHT(email, 4) FROM employees;

-- Extract 4 characters starting at position 2
SELECT SUBSTRING('JavaScript', 2, 4);

-- Get email domain
SELECT SPLIT_PART(email, '@', 2)
FROM employees;
```

Remember: PostgreSQL string positions start from **1**, not 0.

## **4. Replace and modify strings**

| Function      | Purpose                          | Example                                             |
| ------------- | -------------------------------- | --------------------------------------------------- |
| `REPLACE()`   | Replace matching text            | `REPLACE('Hello', 'H', 'Y')` → Yello                |
| `TRANSLATE()` | Replace individual characters    | `TRANSLATE('abc', 'abc', 'xyz')` → xyz              |
| `INITCAP()`   | Capitalize each word             | `INITCAP('hello world')` → Hello World              |
| `OVERLAY()`   | Replace characters at a position | `OVERLAY('Hello' PLACING 'y' FROM 1 FOR 1)` → yello |

```
-- Replace gmail with outlook
SELECT REPLACE(email, 'gmail', 'outlook')
FROM employees;

-- Capitalize names
SELECT INITCAP('rahul kumar');

-- Replace individual characters
SELECT TRANSLATE('12345', '123', 'abc');
```

**REPLACE vs TRANSLATE**

- `REPLACE()` replaces a complete matching substring.
- `TRANSLATE()` replaces individual characters one by one.

## **5. Search functions**

| Function        | Purpose                    | Example                             |
| --------------- | -------------------------- | ----------------------------------- |
| `POSITION()`    | Find position of substring | `POSITION('a' IN 'Java')` → 2       |
| `STRPOS()`      | Find substring position    | `STRPOS('Java', 'a')` → 2           |
| `STARTS_WITH()` | Check starting text        | `STARTS_WITH('Hello', 'He')` → true |
| `SUBSTRING()`   | Extract matching text      | Can use a pattern too               |

```
-- Find position of @ in email
SELECT POSITION('@' IN email)
FROM employees;

-- Search for employees whose name starts with A
SELECT *
FROM employees
WHERE STARTS_WITH(name, 'A');
```

`POSITION()` and `STRPOS()` return 0 when the substring is not found.

## **6. Padding functions**

Used to add characters to make a string a specific length.

| Function | Purpose                 | Example                         |
| -------- | ----------------------- | ------------------------------- |
| `LPAD()` | Add characters on left  | `LPAD('25', 5, '0')` → 00025    |
| `RPAD()` | Add characters on right | `RPAD('Hi', 5, '*')` → Hi\*\*\* |

```
SELECT LPAD('25', 5, '0');

SELECT RPAD('Hello', 8, '*');
```

Use case: Formatting invoice numbers, IDs and codes.

## **7. String functions with WHERE**

You can use string functions to filter records.

```
-- Names in uppercase
SELECT *
FROM employees
WHERE UPPER(name) = 'AMIT SHARMA';

-- Names having more than 5 characters
SELECT *
FROM employees
WHERE LENGTH(name) > 5;

-- Emails from gmail
SELECT *
FROM employees
WHERE email LIKE '%gmail.com';
```

**Interview tip:** Applying a function to a column in `WHERE` can prevent a normal index on that column from being used efficiently. For frequent searches, consider an expression index or a suitable case-insensitive search strategy.

## **8. Advanced: LIKE, ILIKE and regular expressions**

| Operator | Meaning                           | Example           |
| -------- | --------------------------------- | ----------------- |
| `LIKE`   | Pattern matching, case-sensitive  | `name LIKE 'A%'`  |
| `ILIKE`  | Case-insensitive pattern matching | `name ILIKE 'a%'` |
| `~`      | Case-sensitive regex match        | `name ~ '^A'`     |
| `~*`     | Case-insensitive regex match      | `name ~* '^a'`    |
| `!~`     | Does not match regex              | `name !~ '^A'`    |
| `!~*`    | Case-insensitive non-match        | `name !~* '^a'`   |

### **LIKE wildcards**

- `%` → Any number of characters.
- `_` → Exactly one character.

```
-- Starts with A
SELECT * FROM employees WHERE name LIKE 'A%';

-- Ends with a
SELECT * FROM employees WHERE name LIKE '%a';

-- Contains mit
SELECT * FROM employees WHERE name LIKE '%mit%';

-- Exactly 4 characters
SELECT * FROM employees WHERE name LIKE '____';
```

### **Regex examples**

```
-- Starts with A
SELECT * FROM employees WHERE name ~ '^A';

-- Ends with a
SELECT * FROM employees WHERE name ~ 'a$';

-- Contains only digits
SELECT * FROM employees WHERE name ~ '^[0-9]+$';
```

## **9. Advanced: CAST and conversion**

Convert other data types into strings.

```
-- Integer to text
SELECT CAST(123 AS TEXT);

-- PostgreSQL shorthand
SELECT 123::TEXT;

-- Number to formatted text
SELECT TO_CHAR(12345.67, '99,999.99');

-- Date to formatted text
SELECT TO_CHAR(CURRENT_DATE, 'DD-MM-YYYY');
```

`TO_CHAR()` formats numbers and dates as text.

## **10. Other useful PostgreSQL string functions**

| Function                  | Purpose                               |
| ------------------------- | ------------------------------------- |
| `ASCII()`                 | Get ASCII code of first character     |
| `CHR()`                   | Get character from ASCII code         |
| `REPEAT()`                | Repeat string                         |
| `INITCAP()`               | Capitalize words                      |
| `FORMAT()`                | Format a string with placeholders     |
| `QUOTE_LITERAL()`         | Return safely quoted SQL literal text |
| `MD5()`                   | Generate MD5 hash of text             |
| `OCTET_LENGTH()`          | Count bytes                           |
| `BIT_LENGTH()`            | Count bits                            |
| `REGEXP_REPLACE()`        | Replace using regex                   |
| `REGEXP_MATCH()`          | Extract regex matches                 |
| `REGEXP_SPLIT_TO_ARRAY()` | Split text into an array using regex  |

Examples:

```
SELECT REPEAT('Hi ', 3);
-- Hi Hi Hi

SELECT ASCII('A');
-- 65

SELECT CHR(65);
-- A

SELECT REGEXP_REPLACE('abc123', '[0-9]', '', 'g');
-- abc

SELECT REGEXP_SPLIT_TO_ARRAY('red,blue,green', ',');
-- {red,blue,green}
```

## **11. Most important interview differences**

\| Compare | Difference |\
\|---|---|\
\| `UPPER()` vs `LOWER()` | Uppercase vs lowercase |\
\| `LENGTH()` vs `OCTET_LENGTH()` | Characters vs bytes |\
\| `TRIM()` vs `REPLACE()` | Removes characters at ends vs replaces matching text anywhere |\
\| `CONCAT()` vs `||` | CONCAT ignores NULL; `||` propagates NULL |\
\| `SUBSTRING()` vs `LEFT()` | Extract from a position vs extract from beginning |\
\| `LIKE` vs `ILIKE` | Case-sensitive vs case-insensitive |\
\| `REPLACE()` vs `TRANSLATE()` | Substring replacement vs character-by-character replacement |\
\| `POSITION()` vs `STRPOS()` | Different syntax, same basic purpose |

# **Python Virtual Environment (venv) – Beginner Guide**

## **1. What is venv?**

**venv = Virtual Environment**

It creates a separate environment for each Python project to manage its packages (libraries).

Think of it like this:

- Project 1 needs Pandas version 2.
- Project 2 needs Pandas version 3.
- Without venv, package versions may conflict.
- With venv, each project has its own packages.

## **2. Why do we need venv?**

1. Avoid package version conflicts.
2. Keep project dependencies separate.
3. Avoid installing every package globally.
4. Make projects easier to share and deploy.
5. Keep your Python environment clean.

## **3. Which languages use virtual environments?**

| Language   | Environment tools       |
| ---------- | ----------------------- |
| Python     | venv, virtualenv, Conda |
| JavaScript | npm, yarn, pnpm         |
| Java       | Maven, Gradle           |
| Ruby       | Bundler                 |
| PHP        | Composer                |

**Important:** `venv` is specifically a Python tool. Other languages have their own dependency-management tools.

## **4. How to install venv on Windows?**

Usually, you don't need to install it separately. It comes with Python 3.3+.

Check Python installation:

```
python --version
```

Create a virtual environment:

```
python -m venv venv
```

Here:

- `python` → Python interpreter.
- `-m venv` → Run the virtual environment module.
- `venv` → Environment folder name.

## **5. How to activate venv on Windows?**

Open your VS Code terminal (PowerShell).

```
.\venv\Scripts\Activate.ps1
```

After activation, you will see:

```
(venv) PS C:\project>
```

Activated successfully

If PowerShell blocks activation due to execution policy, use Command Prompt instead:

```
venv\Scripts\activate.bat
```

## **6. How to install packages inside venv?**

First activate venv.

Then:

```
pip install pandas
pip install numpy
pip install fastapi
```

Check installed packages:

```
pip list
```

Save dependencies:

```
pip freeze > requirements.txt
```

Install the same dependencies in another environment:

```
pip install -r requirements.txt
```

## **7. How to deactivate venv?**

```
deactivate
```

Your terminal returns to the normal environment.

## **8. Complete workflow**

**Step 1: Create project**

```
mkdir my_project
cd my_project
```

**Step 2: Create venv**

```
python -m venv venv
```

**Step 3: Activate**

```
.\venv\Scripts\Activate.ps1
```

**Step 4: Install packages**

```
pip install pandas numpy
```

**Step 5: Work on your Python project**

Your packages are isolated inside this project.

**Step 6: Deactivate**

```
deactivate
```

## **9. Important interview points**

| Question                                    | Answer                                         |
| ------------------------------------------- | ---------------------------------------------- |
| What is venv?                               | A tool to create isolated Python environments. |
| Why use venv?                               | To avoid dependency conflicts.                 |
| Is venv built into Python?                  | Yes, Python 3.3+.                              |
| Where are packages installed?               | Inside the environment when activated.         |
| Can multiple projects have different venvs? | Yes.                                           |
| Is venv mandatory?                          | No, but recommended.                           |
| Should we upload venv to GitHub?            | No. Add `venv/` to `.gitignore`.               |


## **Pydantic&#x20;**`model_dump()`

`model_dump()` converts a Pydantic model object into a normal Python dictionary (`dict`).

### **1. Why and when do we use it?**

We use it when we want to:

- Convert model data into a dictionary.
- Send structured data as an API response.
- Save data in a database.
- Access or process model data as a dictionary.

### **2. Syntax**

```
model.model_dump()
```

### **3. Example**

```
from pydantic import BaseModelclass Student(BaseModel):    name: str    age: int    course: strstudent = Student(    name="Rahul",    age=25,    course="Python")print(student.model_dump())
```

**Output:**

```
{    'name': 'Rahul',    'age': 25,    'course': 'Python'}
```

### **4. What if we don't use&#x20;**`model_dump()`**?**

```
print(student)
```

Output:

```
name='Rahul' age=25 course='Python'
```

It displays the Pydantic object, not a normal dictionary.

You can still access individual values:

```
print(student.name)  # Rahul
```

But if you need a dictionary, use `model_dump()`.

### **5. Where do we use it in FastAPI?**

Example:

```
@app.post("/students")def create_student(student: Student):    data = student.model_dump()    return data
```

FastAPI receives the request, validates it using Pydantic, and `model_dump()` converts it into a dictionary.

### **6. Useful options**

| Syntax                                 | Purpose                                |
| -------------------------------------- | -------------------------------------- |
| `model.model_dump()`                   | Convert all fields                     |
| `model.model_dump(exclude={"age"})`    | Exclude age                            |
| `model.model_dump(include={"name"})`   | Include only name                      |
| `model.model_dump(exclude_none=True)`  | Exclude fields with `None`             |
| `model.model_dump(exclude_unset=True)` | Exclude fields not explicitly provided |

### **Quick revision**

- **What?** Converts Pydantic object into dictionary.
- **Why?** To process or send data easily.
- **When?** When you need dictionary output.
- **Where?** FastAPI, database operations, data processing.
- **If not used?** You can still use the Pydantic object, but you won't get a normal dictionary automatically.

**Remember:** `model_dump()` gives a Python dictionary, not JSON text. For JSON text, use `model.model_dump_json()`.

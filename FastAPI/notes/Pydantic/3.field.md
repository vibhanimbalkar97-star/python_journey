# **Pydantic Model and Field Rules – Simple Explanation**

## **1. What is a Pydantic Model?**

A **Pydantic Model** is a class that defines what data we expect and validates that data.

Example:

```
from pydantic import BaseModelclass Student(BaseModel):    name: str    age: int    marks: float
```

Here:

- `Student` = Pydantic model.
- `BaseModel` = Parent class.
- `name: str` = Name must be a string.
- `age: int` = Age must be an integer.
- `marks: float` = Marks must be a decimal number.

Hindi: Model म्हणजे कोणता data हवा आणि त्याचा type काय असावा हे define करणे.

## **2. What is Field in Pydantic?**

`Field()` is used to add extra rules and restrictions to model fields.

Example:

```
from pydantic import BaseModel, Fieldclass Student(BaseModel):    name: str = Field(min_length=3, max_length=20)    age: int = Field(gt=0, lt=100)    marks: float = Field(ge=0, le=100)
```

## **3. Important Field rules**

| Rule         | Meaning               | Example         |
| ------------ | --------------------- | --------------- |
| `min_length` | Minimum characters    | `min_length=3`  |
| `max_length` | Maximum characters    | `max_length=20` |
| `gt`         | Greater than          | `gt=0`          |
| `lt`         | Less than             | `lt=100`        |
| `ge`         | Greater than or equal | `ge=0`          |
| `le`         | Less than or equal    | `le=100`        |
| `default`    | Default value         | `default=18`    |

**Easy trick:**

- `gt` = Greater Than (`>`)
- `lt` = Less Than (`<`)
- `ge` = Greater or Equal (`>=`)
- `le` = Less or Equal (`<=`)

## **4. Why do we use Field?**

Suppose frontend sends:

```
{
    "name": "V",
    "age": -5,
    "marks": 150
}
```

Our rules say:

- Name must have at least 3 characters.
- Age must be greater than 0.
- Marks must be between 0 and 100.

Pydantic rejects this invalid data with a validation error.

Hindi: चुकीचा data API मध्ये आला तर Field rules त्याला reject करतात.

## **5. Optional fields and default values**

```
class Student(BaseModel):    name: str    age: int = 18    city: str | None = None
```

- `name` → Required.
- `age` → Optional; default is 18.
- `city` → Optional; default is None.

## **6. Quick revision**

| Concept               | Purpose                 |
| --------------------- | ----------------------- |
| `BaseModel`           | Create a Pydantic model |
| `Field()`             | Add validation rules    |
| `str`, `int`, `float` | Define data types       |
| `default`             | Set default value       |
| `min_length`          | Minimum string length   |
| `gt`, `lt`            | Number restrictions     |
| `None`                | Represents no value     |

**Remember:**

`BaseModel` = What data do I need?

`Field()` = What rules should that data follow?

`Type` = What kind of data should it be?

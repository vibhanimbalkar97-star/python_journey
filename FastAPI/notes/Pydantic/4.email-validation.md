# **Email Validation in FastAPI (Pydantic)**

In FastAPI, we use **Pydantic's&#x20;**`EmailStr` to validate email addresses.

## **1. Install email-validator**

Open your terminal:

```
pip install email-validator
```

## **2. Use EmailStr**

```
from fastapi import FastAPIfrom pydantic import BaseModel, EmailStrapp = FastAPI()class User(BaseModel):    name: str    email: EmailStr@app.post("/users")def create_user(user: User):    return {        "name": user.name,        "email": user.email    }
```

## **3. How does it work?**

Valid email

```
{
    "name": "Vibha",
    "email": "vibha@gmail.com"
}
```

Pydantic accepts the email.

Invalid email

```
{
    "name": "Vibha",
    "email": "vibha123"
}
```

Pydantic automatically returns a **422 Validation Error**.

## **4. Difference between str and EmailStr**

| Type       | Purpose                |
| ---------- | ---------------------- |
| `str`      | Accepts ordinary text  |
| `EmailStr` | Validates email format |

Example:

```
email: str
```

Can accept `"hello123"`.

```
email: EmailStr
```

Checks whether the value has a valid email format.

## **5. Interview revision**

- `EmailStr` comes from Pydantic.
- `email-validator` is an additional required package.
- FastAPI validates the email automatically through Pydantic.
- Invalid input produces a 422 response.
- Email format validation does not prove that the email account actually exists.

**Remember:** `EmailStr` = Email format validation without writing your own validation logic.

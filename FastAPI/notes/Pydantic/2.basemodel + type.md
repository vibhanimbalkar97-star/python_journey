# **Pydantic BaseModel + Type – Simple Hindi Explanation**

## **1. What is BaseModel?**

`BaseModel` is a class provided by Pydantic.

It helps us **validate incoming data and check its data types**.

Hindi: `BaseModel` म्हणजे आपल्या API मध्ये येणारा data योग्य आहे की नाही हे तपासणारा checker.

```
from pydantic import BaseModelclass Student(BaseModel):    name: str    age: int
```

Here:

- `BaseModel` → Pydantic ची base class.
- `Student` → आपला model.
- `name: str` → Name string असायला पाहिजे.
- `age: int` → Age integer असायला पाहिजे.

## **2. What is Type?**

Type म्हणजे data चा प्रकार (Data Type).

| Type    | Meaning         | Example       |
| ------- | --------------- | ------------- |
| `str`   | String          | `"Vibha"`     |
| `int`   | Integer         | `25`          |
| `float` | Decimal         | `25.5`        |
| `bool`  | True/False      | `True`        |
| `list`  | Multiple values | `[10, 20]`    |
| `dict`  | Key-value data  | `{"age": 25}` |

## **3. Why use BaseModel + Type?**

Suppose frontend sends JSON data to FastAPI.

```
{
    "name": "Vibha",
    "age": "25"
}
```

Our expected data:

```
class Student(BaseModel):    name: str    age: int
```

Pydantic checks the data and can convert `"25"` into `25`.

If age is `"hello"`, validation fails.

**Hindi:** Frontend कडून चुकीचा data आला तर Pydantic error देतो. त्यामुळे backend मध्ये चुकीचा data जाण्यापासून संरक्षण मिळते.

## **4. How to use in FastAPI?**

```
from fastapi import FastAPIfrom pydantic import BaseModelapp = FastAPI()class Student(BaseModel):    name: str    age: int@app.post("/student")def create_student(student: Student):    return {        "name": student.name,        "age": student.age    }
```

Frontend JSON:

```
{
    "name": "Vibha",
    "age": 25
}
```

FastAPI receives the JSON → Pydantic validates it → API function receives the validated `student` object.

## **5. What if we don't use BaseModel?**

Without Pydantic:

```
@app.post("/student")def create_student(student: dict):    return student
```

Here:

- Any dictionary can be accepted.
- You need to write validation manually.
- Wrong or missing fields may not be caught automatically.

With Pydantic:

```
class Student(BaseModel):    name: str    age: int
```

You get automatic validation based on the model.

## **6. Role of each concept**

| Concept            | Role                                 |
| ------------------ | ------------------------------------ |
| `BaseModel`        | Creates a validation model           |
| `str`              | Defines string type                  |
| `int`              | Defines integer type                 |
| `float`            | Defines decimal type                 |
| `bool`             | Defines boolean type                 |
| `student: Student` | Says input must follow Student model |
| `student.name`     | Accesses name value                  |

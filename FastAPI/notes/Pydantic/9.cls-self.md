The issue is that your `check_name()` function is **outside the&#x20;**`Student`**&#x20;class**.

You wrote:

```
class Student(BaseModel):    id: str    name: str    age: int@field_validator("name")@classmethoddef check_name(cls, value):    ...
```

Because of the indentation, Python treats `check_name()` as a separate function, not a method of `Student`.

### **1. Correct code**

Move the validator inside the class:

```
from pydantic import BaseModel, Field, EmailStr, field_validatorclass Student(BaseModel):    id: str = Field(..., examples=["S001"])    name: str = Field(..., min_length=2, max_length=50)    age: int = Field(..., gt=0, lt=100)    email: EmailStr    course: str = Field(..., max_length=50)    marks: int = Field(..., ge=0, le=100)    # Custom validation    @field_validator("name")    @classmethod    def check_name(cls, value):        if not value.replace(" ", "").isalpha():            raise ValueError("Name must contain only letters and spaces")        return value.title()s = Student(    id="S002",    name="a b",    age=20,    email="abc@gmail.com",    course="python",    marks=99)print(s.name)
```

Output:

```
A B
```

### **2. Why do we use&#x20;**`cls`**?**

- `cls` represents the Student class.
- It allows access to class-level information and methods.
- Pydantic validators use `cls` to receive the model class.
- `value` contains the actual field value being validated.

### **3. Why not&#x20;**`self`**?**

| `self`                          | `cls`                 |
| ------------------------------- | --------------------- |
| Represents an object            | Represents a class    |
| Used in normal instance methods | Used in class methods |
| Access object data              | Access class data     |

### **Remember**

```
@field_validator("name")@classmethoddef check_name(cls, value):
```

- `@field_validator("name")` → Validate the name field.
- `@classmethod` → Treat the function as a class method.
- `cls` → Student class.
- `value` → Name entered by the user.

**Important:** You don't need to manually call `check_name()`. Pydantic automatically runs it when you create a `Student` object.

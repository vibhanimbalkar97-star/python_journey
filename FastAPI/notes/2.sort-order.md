In FastAPI, we commonly use Python's `sorted()` function to implement **Sort By** and **Order (Ascending / Descending)** logic for JSON data.

Let's understand with a simple example.

## **1. Sample JSON data**

Suppose we have student records:

```
students = [    {"id": 1, "name": "Vibha", "age": 28, "marks": 85},    {"id": 2, "name": "Rahul", "age": 25, "marks": 90},    {"id": 3, "name": "Priya", "age": 30, "marks": 75}]
```

## **2. Sort by a field**

Python provides `sorted()`.

**Syntax:**

```
sorted(data, key=lambda x: x["field"])
```

Example: Sort by age.

```
result = sorted(students, key=lambda x: x["age"])print(result)
```

Output: Age in ascending order (smallest to largest).

25 → 28 → 30

## **3. Ascending and Descending order**

| Order      | Code            | Meaning        |
| ---------- | --------------- | -------------- |
| Ascending  | `reverse=False` | Small to large |
| Descending | `reverse=True`  | Large to small |

Example:

```
# Ascendingsorted(students, key=lambda x: x["age"], reverse=False)# Descendingsorted(students, key=lambda x: x["age"], reverse=True)
```

## **4. FastAPI: Sort By + Order logic**

Let's create an API that accepts `sort_by` and `order` as query parameters.

```
from fastapi import FastAPIapp = FastAPI()students = [    {"id": 1, "name": "Vibha", "age": 28, "marks": 85},    {"id": 2, "name": "Rahul", "age": 25, "marks": 90},    {"id": 3, "name": "Priya", "age": 30, "marks": 75}]@app.get("/students")def get_students(sort_by: str = "age", order: str = "asc"):    result = sorted(        students,        key=lambda x: x[sort_by],        reverse=(order == "desc")    )    return result
```

## **5. How to call API?**

| URL                                  | Result            |
| ------------------------------------ | ----------------- |
| `/students?sort_by=age&order=asc`    | Age: 25, 28, 30   |
| `/students?sort_by=age&order=desc`   | Age: 30, 28, 25   |
| `/students?sort_by=marks&order=asc`  | Marks: 75, 85, 90 |
| `/students?sort_by=marks&order=desc` | Marks: 90, 85, 75 |

## **6. Understand the important logic**

```
key=lambda x: x[sort_by]
```

- `x` = one student dictionary.
- `sort_by` = field name, such as `"age"`.
- `x[sort_by]` = gets that student's age.

```
reverse=(order == "desc")
```

- If order is `"desc"` → `True`.
- If order is `"asc"` → `False`.

**Important:** In production, validate the allowed fields and order values before sorting. Otherwise, an invalid field can cause a `KeyError`.

```
if sort_by not in ["id", "name", "age", "marks"]:    return {"error": "Invalid sort field"}if order not in ["asc", "desc"]:    return {"error": "Invalid order"}
```

## **7. Quick interview revision**

| Concept         | Meaning                     |
| --------------- | --------------------------- |
| `sorted()`      | Returns a new sorted list   |
| `sort()`        | Sorts the original list     |
| `key`           | Decides which field to sort |
| `lambda`        | Small anonymous function    |
| `reverse=True`  | Descending                  |
| `reverse=False` | Ascending                   |

**Remember:**

- Sort By = Which field? (`age`, `name`, `marks`)
- Order = In which direction? (`asc`, `desc`)

Try changing `sort_by` and `order` in the API URLs to understand how the sorting changes.

No. Python does not have a built-in function called `tosorted()`.

You can use:

1. `sorted()` – Returns a new sorted list.
2. `.sort()` – Sorts the original list in place.

Example:

```
numbers = [5, 2, 8, 1]# Using sorted()result = sorted(numbers)print(result)   # [1, 2, 5, 8]print(numbers)  # [5, 2, 8, 1]# Using sort()numbers.sort()print(numbers)  # [1, 2, 5, 8]
```

### **Difference**

| Feature            | sorted()        | sort()        |
| ------------------ | --------------- | ------------- |
| Type               | Function        | List method   |
| Returns            | New sorted list | None          |
| Changes original?  | No              | Yes           |
| Works with tuples? | Yes             | No, list only |

**In FastAPI:** Prefer `sorted()` when you want to sort JSON records without modifying the original list.

```
result = sorted(students, key=lambda x: x["age"])
```

# **Pagination in FastAPI (Beginner-friendly)**

**Pagination means dividing a large amount of data into smaller pages.**

Example: We have 100 students, but we want to display only 10 students per page.

- Page 1 → Students 1–10
- Page 2 → Students 11–20
- Page 3 → Students 21–30

## **1. Understand two important parameters**

| Parameter | Meaning                    |
| --------- | -------------------------- |
| `page`    | Which page do you want?    |
| `limit`   | How many records per page? |

## **2. Pagination formula**

```
skip = (page - 1) * limit
```

**Why?**

Suppose `page = 2` and `limit = 10`.

```
skip = (2 - 1) * 10skip = 10
```

It skips the first 10 records and gets the next 10.

## **3. FastAPI example**

```
from fastapi import FastAPIapp = FastAPI()students = [    {"id": i, "name": f"Student {i}"}    for i in range(1, 51)]@app.get("/students")def get_students(page: int = 1, limit: int = 10):    skip = (page - 1) * limit    result = students[skip : skip + limit]    return {        "page": page,        "limit": limit,        "total": len(students),        "data": result    }
```

## **4. How to call API?**

| API URL                     | Result         |
| --------------------------- | -------------- |
| `/students?page=1&limit=10` | Students 1–10  |
| `/students?page=2&limit=10` | Students 11–20 |
| `/students?page=3&limit=10` | Students 21–30 |
| `/students?page=1&limit=5`  | Students 1–5   |

## **5. Understand slicing logic**

```
result = students[skip : skip + limit]
```

Python slicing:

```
students[10:20]
```

Means get records from index 10 up to index 19 (20 is excluded).

## **6. Important: Validate page and limit**

Use FastAPI's `Query`:

```
from fastapi import Query@app.get("/students")def get_students(    page: int = Query(1, ge=1),    limit: int = Query(10, ge=1, le=100)):    skip = (page - 1) * limit    result = students[skip : skip + limit]    return result
```

- `ge=1` → Page must be at least 1.
- `le=100` → Limit cannot exceed 100.

## **7. Quick revision**

| Concept                 | Meaning                |
| ----------------------- | ---------------------- |
| Pagination              | Divide data into pages |
| page                    | Current page number    |
| limit                   | Records per page       |
| skip                    | Records to skip        |
| `(page-1)*limit`        | Calculate skip         |
| `data[skip:skip+limit]` | Get current page       |

**Remember this formula:**

\\[ skip = (page-1) \times limit \\]

Pagination is especially useful when your database contains thousands of records. In real projects, use database-level pagination (`OFFSET/LIMIT` in SQL or `skip/limit` in MongoDB) instead of loading every record into Python first.

**Offset means how many records to skip before fetching the data.**

Example: You have 20 students and want 5 students per page.

| Page | Offset | Records |
| ---- | ------ | ------- |
| 1    | 0      | 1–5     |
| 2    | 5      | 6–10    |
| 3    | 10     | 11–15   |
| 4    | 15     | 16–20   |

**Formula:**

```
offset = (page - 1) * limit
```

Example:

```
page = 2limit = 5
offset = (page - 1) * limit
print(offset)  # 5
```

It skips the first 5 records and fetches the next 5.

**Remember:**

- `offset` = How many records to skip.
- `limit` = How many records to fetch.

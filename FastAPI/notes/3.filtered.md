@app.get('/filter')
def filtered(course):
    data = load_data()

    if course is None:
        return data

    filtered = {}
    for student_id, info in data.items():
        if info["course"] == course:
            filtered[student_id] = info
        print(filtered)
    return filtered

### **Understand this line**

```
filtered[student_id] = info
```

- `filtered` → Empty dictionary `{}`.
- `student_id` → Student's ID (1, 2, 3).
- `info` → Complete student information.

Think of it like:

```
filtered[1] = {"name": "Vibha", "course": "Python"}filtered[3] = {"name": "Priya", "course": "Python"}
```

```

```

**Remember:**

`dictionary[key] = value`

It means add or update a key-value pair in a dictionary.

Here, we are adding only students whose course is Python.

**Hindi trick:** `filtered[student_id] = info` म्हणजे filtered dictionary मध्ये त्या student ची ID आणि पूर्ण माहिती store करणे.

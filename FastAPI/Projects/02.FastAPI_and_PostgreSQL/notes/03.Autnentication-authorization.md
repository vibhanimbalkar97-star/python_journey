## **1. What is Authentication?**

Authentication means **Who are you?**

Example:

You open your Student Management API. Before accessing student records, you must log in using:

- Email
- Password

If your credentials are correct, the server allows you to log in.

Hindi: Authentication ka matlab hai user ki identity verify karna.

## **2. What is Authorization?**

Authorization means **What are you allowed to access?**

Example:

Suppose your application has two users:

| User        | Permission                            |
| ----------- | ------------------------------------- |
| Admin       | Create, Read, Update, Delete students |
| Normal User | Only view students                    |

Both users can log in, but their permissions are different.

Hindi: Authorization ka matlab hai user ko kya karne ki permission hai.

## **3. What is JWT?**

JWT = JSON Web Token.

JWT is a token that the server generates after successful login.

This token is sent to the client (React frontend), and the client sends it with future API requests.

**Simple flow:**

1. User enters email and password.
2. FastAPI verifies credentials.
3. FastAPI generates JWT token.
4. React receives the token.
5. React sends the token with API requests.
6. FastAPI verifies the token.
7. If valid, the user can access protected routes.

## **5. Step-by-step topics to learn**

Follow this order:

1. **User Registration**

   Create a new user with name, email and password.
2. **Password Hashing**

   Never store plain-text passwords in PostgreSQL. Learn to hash passwords using bcrypt or Argon2.
3. **User Login**

   Verify email and password.
4. **JWT Token Creation**

   Learn access tokens, payload, secret key and expiration time.
5. **JWT Token Verification**

   Verify tokens using FastAPI dependencies.
6. **Protect API Routes**

   Use `Depends()` to restrict access to logged-in users.
7. **Role-Based Authorization**

   Implement Admin and Normal User permissions.

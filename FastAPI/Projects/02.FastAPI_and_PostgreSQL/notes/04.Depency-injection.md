## **What is Dependency Injection (DI) in FastAPI?**

**Dependency Injection means reusing code by providing required functionality to an API endpoint instead of writing the same code repeatedly.**

In simple Hindi:

Dependency Injection ka matlab hai ki jis function ko kisi cheez ki zarurat hai, woh cheez FastAPI automatically provide karta hai.

### **1. Why do we use it?**

Suppose you have 3 API endpoints:

- `/students`
- `/students/{id}`
- `/students/delete/{id}`

All three need a database connection.

Without Dependency Injection, you might create a database connection separately in every endpoint.

With DI, you write the database connection logic once and reuse it.

### **2. Simple example**

**Step 1: Create a dependency function**

```
from fastapi import Depends, FastAPIapp = FastAPI()def get_db():    db = "Database Connection"    return db
```

Here:

- `get_db()` provides a database connection.
- We write this function only once.

**Step 2: Inject dependency into API**

```
@app.get("/students")def get_students(db = Depends(get_db)):    return {"message": db}
```

Output:

```
{
    "message": "Database Connection"
}
```

### **3. Understand&#x20;**`Depends()`

```
db = Depends(get_db)
```

| Part        | Meaning                               |
| ----------- | ------------------------------------- |
| `Depends()` | FastAPI dependency system             |
| `get_db`    | Function that provides the dependency |
| `db`        | Variable receiving the returned value |

**Important:** You pass `get_db`, not `get_db()`.

FastAPI calls the function and injects its returned value.

### **4. Real PostgreSQL example with SQLAlchemy**

In your FastAPI + PostgreSQL project, you can use:

**database.py**

```
from sqlalchemy.orm import Sessionfrom database import SessionLocaldef get_db():    db = SessionLocal()    try:        yield db    finally:        db.close()
```

**student.py**

```
from fastapi import APIRouter, Dependsfrom sqlalchemy.orm import Sessionfrom database import get_dbrouter = APIRouter()@router.get("/students")def get_students(db: Session = Depends(get_db)):    return db.query(Student).all()
```

Here:

1. API receives a request.
2. FastAPI calls `get_db()`.
3. Database session is created.
4. Session is injected into `db`.
5. API performs the database operation.
6. `finally` closes the session.

`yield` allows cleanup code to run after the request finishes.

### **5. Where do we use Dependency Injection?**

| Use case       | Example              |
| -------------- | -------------------- |
| Database       | PostgreSQL session   |
| Authentication | Get logged-in user   |
| Authorization  | Check admin role     |
| Configuration  | Application settings |
| Reusable logic | Pagination           |
| Security       | Verify access token  |

### **6. Interview question**

**Q: What is Dependency Injection in FastAPI?**

Answer:

Dependency Injection is a mechanism in FastAPI that allows us to reuse and manage common functionality by injecting dependencies into path operations using `Depends()`.

**Remember these three things:**

- `Depends()` → Injects dependencies.
- `get_db()` → Provides database session.
- `yield` → Provides the session and allows cleanup.
